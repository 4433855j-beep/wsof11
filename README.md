# PC Link — 휴대폰으로 내 노트북 원격 조작

휴대폰 브라우저(또는 홈 화면에 설치한 앱)에서 노트북의 **파일·폴더, 프로그램, 화면**을 직접 조작하는 개인용 도구입니다.
노트북에서 작은 서버를 실행하고, 휴대폰으로 그 주소에 접속하는 방식입니다. 별도 앱스토어 설치가 필요 없습니다.

## 1. 주요 기능

| 탭 | 기능 |
|---|---|
| 📁 파일 | 드라이브·폴더 탐색, 휴대폰으로 다운로드(폴더는 ZIP), 휴대폰 → PC 업로드, 새 폴더/새 텍스트 파일, 이름 바꾸기, 복사·이동(붙여넣기), 휴지통/영구 삭제, 이름 검색, 텍스트 파일 편집(UTF-8·CP949), 사진·동영상·음악·PDF 미리보기, **PC에서 기본 프로그램으로 열기**, 길게 눌러 여러 개 선택 |
| 🧩 프로그램 | 설치된 프로그램 목록(Windows 시작 메뉴, macOS 응용 프로그램, Linux .desktop)에서 골라 실행, 실행 중인 프로세스 확인·종료·강제 종료 |
| 🖥 화면 | PC 화면 실시간 보기, 화면을 눌러 클릭·더블클릭·우클릭·마우스 이동, 스크롤, 글자 입력(한글 포함), 단축키(복사/붙여넣기/창 전환/창 닫기/시작/바탕화면), 볼륨·재생 제어 |
| ⚙ 시스템 | CPU·메모리·디스크·배터리 상태, 휴대폰↔PC 클립보드 주고받기, 화면 잠금·절전·다시 시작·종료(1분 유예, 취소 가능), 터미널 명령(기본 꺼짐) |

## 2. 설치 및 실행 (노트북)

**필요 조건**: Python 3.10 이상 (Windows는 [python.org](https://www.python.org/downloads/)에서 설치할 때 “Add python.exe to PATH”를 체크)

1. 이 저장소를 내려받아 압축을 풉니다.
2. 실행
   - **Windows**: `start-windows.bat` 더블클릭
   - **macOS / Linux**: 터미널에서 `./start-mac-linux.sh`
   - 처음 실행할 때만 필요한 부품을 자동 설치합니다(1~3분).
3. 창에 표시되는 **QR 코드**를 휴대폰 카메라로 찍으면 바로 연결됩니다.
   (또는 `휴대폰 주소`를 휴대폰 브라우저에 입력하고 `접속 코드`를 입력)
4. 휴대폰 브라우저 메뉴에서 **“홈 화면에 추가”** 를 누르면 앱처럼 아이콘으로 실행됩니다.

> 처음 실행할 때 Windows 방화벽 허용 창이 뜨면 **“개인 네트워크”만** 허용하세요.
> macOS는 화면 보기·마우스 조작을 위해 *시스템 설정 → 개인정보 보호 및 보안*에서 터미널(또는 Python)에 **화면 기록**과 **손쉬운 사용** 권한을 줘야 합니다.

### 명령어 옵션
```
python -m pclink                 # 실행
python -m pclink --port 9000     # 포트 변경
python -m pclink --show-token    # 접속 코드 확인
python -m pclink --reset-token   # 접속 코드 재발급(기존 휴대폰 모두 로그아웃)
```

## 3. 집 밖(LTE·5G)에서 접속하려면

기본은 **같은 와이파이**에서만 동작합니다. 외부에서 쓰려면 공유기 포트포워딩 대신 **Tailscale**(무료 개인용 VPN)을 권장합니다.

1. 노트북과 휴대폰에 Tailscale 설치 후 같은 계정으로 로그인
2. 노트북에서 `tailscale serve --bg 8765` 실행 → `https://노트북이름.xxx.ts.net` 주소가 생김(HTTPS 자동 적용)
3. 휴대폰에서 그 주소로 접속

> 공유기 포트포워딩으로 인터넷에 직접 노출하는 방식은 권장하지 않습니다.

## 4. 설정 (`~/.pclink/config.json`)

Windows 기준 `C:\Users\사용자\.pclink\config.json` 입니다. 수정 후 다시 실행하면 적용됩니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `token` | 자동 생성 | 접속 코드(32자 무작위) |
| `port` | `8765` | 포트 |
| `allowed_roots` | `[]` (전체) | 접근 허용 폴더 제한. 예: `["C:\\Users\\홍길동\\Documents", "D:\\자료"]` |
| `enable_remote_screen` | `true` | 화면 보기·마우스·키보드 |
| `enable_power` | `true` | 잠금·절전·재시작·종료 |
| `enable_terminal` | `false` | 휴대폰에서 명령어 실행 (위험, 필요할 때만 켜기) |
| `apps` | `[]` | 자주 쓰는 프로그램 직접 등록. 예: `[{"name": "메모장", "command": ["notepad.exe"]}]` |
| `cert_file`, `key_file` | 빈 값 | HTTPS 인증서(직접 구성할 때) |

## 5. 보안 설계

- **접속 코드 인증**: 처음 1회 접속 코드로 로그인 → 30일짜리 세션 쿠키(HttpOnly, SameSite=Strict) 발급
- **무차별 대입 차단**: 같은 IP에서 5회 틀리면 5분간 로그인 차단
- **경로 검증**: 모든 경로를 절대경로로 정규화하고 `allowed_roots` 밖, `..` 우회, 범위 밖을 가리키는 바로가기(심볼릭 링크) 접근을 차단. 업로드 파일명에 포함된 경로는 제거
- **프로그램 실행 제한**: 휴대폰에서 임의 명령을 보낼 수 없고, PC에서 찾은 목록 또는 `config.json`에 등록한 프로그램만 실행(터미널 기능은 기본 꺼짐)
- **위험 동작 확인**: 삭제·종료·재시작은 휴대폰에서 한 번 더 확인. 종료·재시작은 1분 유예 후 실행되어 취소 가능
- **감사 로그**: 로그인(성공·실패), 업로드·다운로드·수정·삭제·실행·전원·터미널 기록을 `~/.pclink/audit.log`에 남김
- **기본 삭제는 휴지통**: 운영체제 휴지통으로 이동(send2trash 미설치 시 `~/.pclink/trash`)

### ⚠ 사용 시 유의사항
- **개인 소유 노트북에서만 사용하세요.** 기관 업무용 PC·업무망 PC에 원격제어 프로그램을 설치하는 것은 소속 기관의 정보보안 지침에 따라 금지되거나 사전 승인이 필요할 수 있습니다. 설치 전에 기관 정보보안 담당 부서에 확인하세요.
- 공용 와이파이(카페·도서관 등)에서는 실행하지 마세요. 같은 네트워크 사용자가 접속을 시도할 수 있습니다(접속 코드가 없으면 차단되지만, http 통신은 암호화되지 않습니다). 외부에서는 위 3번의 Tailscale(HTTPS)을 쓰세요.
- 접속 코드가 노출됐다면 `python -m pclink --reset-token` 으로 즉시 재발급하세요.
- 사용하지 않을 때는 실행 창을 닫으세요(Ctrl+C).

## 6. 구조

```
pclink/
  __main__.py        실행 진입점(주소·QR 출력)
  app.py             인증 미들웨어, 라우터 조립, 웹앱 제공
  security.py        세션·차단·경로 검증·감사 로그
  files.py           파일·폴더 API
  system.py          시스템 정보·프로그램·프로세스·전원·클립보드·터미널 API
  screen.py          화면 캡처·마우스·키보드 API
  platform_utils.py  Windows/macOS/Linux별 처리
  web/               휴대폰용 웹앱(PWA)
tests/               자동 테스트 (python -m pytest)
```

## 7. 알려진 제한
- 화면 보기는 **주 모니터**만 지원하며, 0.8초 간격 이미지 갱신 방식이라 동영상처럼 매끄럽지는 않습니다.
- Windows의 관리자 권한 창(UAC 확인창 등)은 보안상 원격 클릭이 되지 않습니다.
- Windows의 `절전`은 최대 절전 모드가 켜져 있으면 최대 절전으로 들어갈 수 있습니다.
- Linux에서 화면 조작을 쓰려면 `python3-tk` 패키지가 필요하며 Wayland 세션에서는 동작이 제한됩니다.
